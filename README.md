# K-에듀파인 예산 대시보드

K-에듀파인에서 내려받은 `예산현액(일상경비 포함)` 예산 파일에 최적화된 예산 집행 현황 대시보드 실행 파일입니다.

## 주요 기능

- K-에듀파인 예산현액 엑셀 원본 파일 기반 대시보드 생성
- 사업 → 단위사업 → 세부 예산항목 3단계 드릴다운
- 총 예산현액, 원인행위액, 지출액, 일상경비 교부·지출 현황 표시
- 예산항목별 5자리 코드, 원가통계비목, 산출기초, 기준한도, 검증상태 표시
- 사업별 및 단위사업별 예산항목 XLSX 다운로드
- 저시력자도 보기 쉽도록 큰 글씨와 고대비 UI 적용

## 포함 파일

| 파일 | 설명 |
|---|---|
| `2.대시보드_실행.exe` | Windows 실행 파일 |
| `사용방법.txt` | 실행 및 사용 안내 |
| `README.md` | 프로젝트 안내 |
| `.gitignore` | Git 제외 규칙 |

## 사용 방법

1. K-에듀파인에서 `예산현액(일상경비 포함)` 엑셀 파일을 내려받습니다.
2. `2.대시보드_실행.exe`를 실행합니다.
3. 파일 선택 창에서 예산현액 엑셀 파일을 선택합니다.
4. 같은 폴더에 `budget_dashboard.html`이 생성되고 브라우저에서 열립니다.

자세한 내용은 `사용방법.txt`를 참고하세요.

## 최적화 대상

이 프로그램은 K-에듀파인 예산 파일의 다음 구조에 맞춰 제작되었습니다.

- `사업항목`
- `원가통계비목`
- `산출기초`
- `예산현액`
- `원인행위액`
- `지출액`
- `일상경비 교부액`

다른 회계시스템이나 임의 편집된 엑셀 파일에서는 일부 항목이 정상 인식되지 않을 수 있습니다.

## 주의사항

- Windows 환경에서 실행하는 것을 기준으로 합니다.
- 엑셀 원본 파일이 열려 있으면 처리 중 오류가 날 수 있으므로 닫은 뒤 실행하세요.
- 생성되는 HTML은 로컬 파일이며 인터넷 연결 없이 열 수 있습니다.
- 예산 기준 검증은 참고용이며, 최종 집행 가능 여부는 기관 지침과 최신 예산편성 기준을 확인해야 합니다.
