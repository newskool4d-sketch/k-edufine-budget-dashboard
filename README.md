# K-에듀파인 예산 대시보드

K-에듀파인에서 내려받은 `예산현액(일상경비 포함)` 예산 파일에 최적화된 예산 집행 현황 대시보드 실행 파일입니다.

## 주요 기능

- K-에듀파인 예산현액 엑셀 원본 파일 기반 대시보드 생성
- 사업 → 단위사업 → 세부 예산항목 3단계 드릴다운
- 총 예산현액, 원인행위액, 지출액, 일상경비 교부·지출 현황 표시
- 예산항목별 5자리 코드, 원가통계비목, 산출기초, 기준한도, 검증상태 표시
- **예상질의 생성**: 단위사업별 주요예산사업보고 예상질의 답변 자동 생성(상반기 보고 대비)
- **감사 대비 참고 진단**: 자동 점검 후보 분류 + 조치 등록 연계(공식 감사 지적·적정 판정이 아님)
- **시점 비교**: 이전 시점 파일과 지출·예산(추경) 변동 비교
- **조치관리**: 항목별 담당부서·회신기한·조치상태 입력 및 XLSX·JSON 내보내기(이력·종결근거·기한도과 배지 포함)
- **1쪽 요약 브리핑**·**지적사항 처리계획서**: 원장·의회 보고, 수감자료 서식 자동 생성
- 특별교부금(특교) 사업 배지·필터, 화면 내 사용설명서·용어 풀이
- 사업별·단위사업별 예산항목 XLSX 다운로드, 보고서 HTML·MD·TXT 저장
- 세부 표 컬럼 정렬·표시/숨김 관리, 필터 그룹화, **라이트/다크 모드 전환**
- 읽기 쉬운 본문·불투명 데이터 표면, 키보드 탐색·Esc 닫기 지원(전체 접근성 적합성 인증은 아님)

## 2026-09-24 시의회 보고 대응 고도화

- **보고 수치 착시 방지**: 전체 지출률과 함께 전출·이전 제외 지출률 표시, 원장 지출액(원본 H열) → 실제 지출액 대사 카드, 신속집행 목표율 근거(공문) 미입력 시 ‘참고치’ 표기
- **월별 추이·전년 동기**: `예산현액_YYYY-MM-DD.xlsx` 형식으로 모은 월말 원본 폴더를 지정하면 올해·전년·참고 목표 추이 그래프와 사업별 전년 동기 비교. 목표 대비 미달 단위사업 순위
- **의회 보고 표**: 주요예산사업 내역(백만원)·교특결산 사업개요(천원) 초안 Markdown, 원본으로 채울 수 없는 칸은 [확인 필요]. 명령줄 `--emit-md 폴더 --hwpx`로 한글(HWPX) 변환(한글 설치 PC)
- **결산·성과**: 이월(명시·사고)·불용 사유 4분류 대사, 근거 문서가 있을 때만 성과 실적 표시, 교부금 정산·반납 예정액
- **증빙·백업**: 요구자료별 증빙 보관 경로와 답변서 끝 증빙 목록, 조치·행감·재원·결산 기록을 한 파일로 백업·복원
- **여러 기관 비교**: 명령줄 `--rollup "기관=파일" --rollup "기관=파일"`로 기관별 집행 비교 보고서(항목은 합치지 않음)
- 화면: 유리 효과 기본 끔, 영문 라벨·이모지 제거, 천원 단위 표시, 1366px에서 핵심 8열 가로 넘침 해소, 0건 검색 안내 표시 결함 수정

검증: 자동 테스트 410개 통과, 실제 XLSX 입력의 Python·EXE 생성 HTML 해시 일치, EXE의 기관 합산·Markdown 출력 실행 확인, 의회 보고 표 HWPX를 한글에서 열어 PDF 출력 확인. EXE는 36,264,244바이트, SHA-256 `84a9c6753de3b095b2a6fe1d3f75ed4e573667d5c2292f2458a5488d5b090432`입니다. 월별 추이·결산 기능은 실제 월말 원본·결산 자료로는 아직 검증하지 않았고(합성 자료로 검증), GUI 대화상자 전체 조작은 미검증입니다. 실행 파일은 코드서명되지 않았습니다.

## 2026-09-09 Clear Glass 02 · 행감 작업공간

- 일반·다크 공통 글래스 디자인, 업무 아이콘 메뉴, 예산 중심 7:5 총괄 배치
- 자료관리·설정에서 유리 효과 켬/끔 선택. 표·답변 입력은 불투명 표면 유지
- 기본 핵심 8열, 원 단위 금액/축약 선택, 사업·단위 경로, 검색·필터·열 구성 2단 도구 모음
- 요구자료 목록·답변·근거 분할 화면. 1600px 미만에서는 답변/근거 전환
- 실제 저장·백업·가져오기, 답변 변경 시 재검토, 미저장 이동 확인과 손상 기록 보호
- 지원재원 대장: 국가 목적지원·지자체 목적지원·교육청 일반재원·기타. 근거 미확인은 미확인으로 유지
- 자료 기준일·기관 범위·원본 대사 확인. 확인이 끝나지 않은 답변서는 검토 전 초안으로 출력
- 이번 실행 파일은 새 생성기·작업공간을 포함해 재빌드. 이전 ver8은 과거 버전

실제 예산 원본과 내부 생성 HTML은 이 저장소에 포함하지 않습니다. 입력 자료·담당자 검토·공식 문서 확인은 별도로 필요합니다.

검증: 자동 테스트 348개 통과, 일반·다크/반응형과 불투명 모드 브라우저 검사, 실제 XLSX 입력의 Python·EXE 생성 HTML 해시 일치. EXE는 36,272,429바이트(약 36.3MB), SHA-256 `b220cd54c1ecad44be26f8f3380ae8eedf7800964b784b9e19375fa6b81d56f0`입니다. 브라우저 검증은 localhost에서 수행했으며, file:// 직접 저장 및 전체 GUI 대화상자 조작은 별도 미검증입니다. 실행 파일은 코드서명되지 않았습니다.

- 컬럼 표시 복원 시 `data-action` 기반 선택자로 동작해 동적 이벤트 위임과 일관성 유지

## 사용 방법

1. K-에듀파인에서 `예산현액(일상경비 포함)` 엑셀 파일을 내려받습니다.
2. `2.대시보드_실행.exe`를 실행합니다.
3. 파일 선택 창에서 예산현액 엑셀 파일을 선택합니다.
4. 기관명과 원본 집행자료 기준일을 확인해 입력합니다. 기준일을 모르면 빈칸으로 두세요.
5. 같은 폴더에 `budget_dashboard_YYYY-MM-DD.html`이 생성되고 브라우저에서 열립니다. 파일명의 날짜는 생성일이며 자료 기준일과 다릅니다. 같은 날 기존 산출물을 보존하려면 별도 이름으로 보관하세요.

자세한 내용은 `사용방법.txt`를 참고하세요.

## 최적화 대상

이 프로그램은 K-에듀파인 예산 파일의 다음 구조에 맞춰 제작되었습니다.

- `사업항목`
- `원가통계비목`
- `산출기초`
- `예산현액`
- `원인행위액`
- `지출액`
- `일상경비 교부액`

다른 회계시스템이나 임의 편집된 엑셀 파일에서는 일부 항목이 정상 인식되지 않을 수 있습니다.

## 주의사항

- Windows 환경에서 실행하는 것을 기준으로 합니다.
- 엑셀 원본 파일이 열려 있으면 처리 중 오류가 날 수 있으므로 닫은 뒤 실행하세요.
- 생성되는 HTML은 로컬 파일이며 인터넷 연결 없이 열 수 있습니다.
- 예산 기준 검증은 참고용이며, 최종 집행 가능 여부는 기관 지침과 최신 예산편성 기준을 확인해야 합니다.
- `특교` 등 사업명은 지원재원 확정 근거가 아닙니다. 교부·배정 문서로 확인하세요.
- 기록은 브라우저·기관별 로컬 저장입니다. PC·브라우저·기관명·파일 경로 변경 전에 행감/재원/조치 JSON을 각각 백업하세요.
- 직접 인쇄는 출력 안내만 표시합니다. 보고·제출에서 답변서 HTML을 내려받아 인쇄하거나 기존 보고서/PDF를 사용하세요.
