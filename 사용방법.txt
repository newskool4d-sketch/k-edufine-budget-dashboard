예산 집행 현황 대시보드 - 사용 방법
=============================================

[전체 흐름]

  1. 예산현액.xlsx   ← 예산시스템(재정사업관리->예산관리->예산편성->사업관리카드-> 회계연도 선택 ->예산현액(일상경비포함 체크) -> 파일 내려받기) 에서 내려받은 원본 파일(별도 가공 필요 없음) 
           ↓
  2.대시보드_실행.exe 더블클릭
    → 파일 선택 창: 예산현액.xlsx 선택
           ↓
  budget_dashboard.html 생성 → 브라우저 자동 오픈 → 집행 현황 시각화
  사업별 xlsx 파일로 다운로드 가능 

[파일 구성]

  2.대시보드_실행.exe       ← 실행 파일 (더블클릭)
  run_budget_dashboard.py    ← 대시보드 생성 스크립트
  budget_dashboard.html      ← 생성된 대시보드 예시
 

[화면 구성 - 3단계 드릴다운]

  1단계: 개요
    - KPI 카드: 총 예산현액 / 원인행위액 / 지출액 / 일상경비 교부액 / 기준 확인 항목 / 한도 초과 의심
    - 사업별 카드: 사업명, 예산 요약, 단위사업·운영유형·세부항목 수, 목 그룹 태그

  2단계: 사업 클릭 → 단위사업별 현황
    - 해당 사업의 단위사업 카드 목록
    - 각 단위사업별 예산현액·원인행위율·지출률·운영유형·기준확인 건수 표시
    - [사업 XLSX 다운로드] 버튼으로 해당 사업의 전체 세부항목을 엑셀 파일로 저장

  3단계: 단위사업 클릭 → 세부 예산항목 테이블
    - 목 그룹, 운영유형, 세부경로, 예산항목, 5자리 코드, 원가통계비목, 산출기초
    - 추출단가, 기준한도, 근거쪽, 검증상태(적정/확인/초과)
    - 예산현액, 원인행위액, 지출액, 일상경비 교부액·지출액·잔액, 등급, 점검메모
    - [단위사업 XLSX 다운로드] 버튼으로 현재 단위사업 세부항목만 엑셀 파일로 저장

[예산편성 기준 반영 내용]

  - 원가통계비목 7자리 코드에서 앞 5자리 코드를 자동 표시합니다.
    예: [2100605] 강사수당 → 21006 운영수당
  - reference/budget_rules.json 기준표를 우선 반영합니다.
  - 기준표가 없거나 exe만 단독 실행하는 경우에도 기본 내장 기준을 사용합니다.
  - 산출기초의 첫 금액(예: 50,000원×3명×3시간)을 추출단가로 읽어 한도와 비교합니다.
  - 정액 한도가 아닌 계약·실비·견적 기준 항목은 "확인"으로 표시합니다.
  - PDF 원본: reference/2026 인천광역시 교육비특별회계 예산편성 기본지침.pdf

[원본 구조 반영 내용]

  - 예산현액.xlsx 한 파일만 사용합니다.
  - [210] 운영비, [220] 여비, [230] 업무추진비, [430] 유형자산 등 목 그룹을 보존합니다.
  - 동일 사업명이 여러 목 그룹에 반복되어도 사업별로 합산하고, 세부항목에는 목 그룹을 표시합니다.
  - 운영유형 아래의 가), (1), (가) 같은 하위 산출 경로도 세부경로로 보존합니다.
  - 이전 자료와 비교하고 싶다면 별도 폴더를 만들어서 html, xlsx 파일을 저장하는 것도 방법입니다.

[등급 기준]

  주의  : 원인행위 0원, 원인행위잔액 음수, 일상경비 교부잔액 음수
  관찰  : 원인행위율 30% 미만, 또는 원인행위 있으나 지출 0원
  정상  : 위 조건 해당 없음

[기준 검증 상태]

  적정  : 추출단가가 기준한도 이하
  확인  : 정액 한도가 없거나 세부 기준 확인이 필요한 항목
  초과  : 추출단가가 기준한도를 초과한 것으로 의심되는 항목

[가독성 개선]

  - 본문·표·KPI 폰트 크기를 확대했습니다.
  - 저시력자도 읽기 쉽도록 배경 대비와 행 간격을 키웠습니다.
  - 기존 3단계 드릴다운 구조는 유지했습니다.

[엑셀 다운로드]

  - 사업 상세 화면: 사업 전체 예산항목을 .xlsx 파일로 다운로드합니다.
  - 단위사업 상세 화면: 현재 단위사업 예산항목만 .xlsx 파일로 다운로드합니다.
  - 다운로드 파일에는 화면의 주요 컬럼과 기준 검증 컬럼이 함께 포함됩니다.
  - 인터넷 연결이나 별도 엑셀 라이브러리 없이 HTML 내부 기능으로 생성됩니다.

[참고]

- 엑셀 파일이 열려 있으면 오류가 발생할 수 있습니다. 파일을 닫고 실행하세요.
- budget_dashboard.html 은 인터넷 연결 없이도 동작합니다.
- 데이터가 바뀔 때마다 exe 를 다시 실행하면 최신 현황이 반영됩니다.
