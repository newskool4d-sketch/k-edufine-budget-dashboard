예산 집행 현황 대시보드 - 사용 방법
=============================================

[2026-11-12 화면 개편·선택 목록 통합]
  - 총괄 현황 맨 위의 "예산 집행 현황" 띠에서 예산현액·실제 지출액·집행잔액·지출률을
    한 줄로 보고, 막대의 세로선으로 목표(또는 참고 목표) 집행률을 확인합니다.
  - 왼쪽 메뉴는 화면 높이로 고정되고, 위쪽 제목 줄은 화면과 함께 움직입니다.
    좁은 화면(휴대전화)에서는 위쪽 메뉴를 옆으로 밀어 다른 메뉴를 엽니다.
  - 저장 버튼 묶음은 [저장 형식] 선택 목록 + [저장] 버튼 하나로 바뀌었습니다.
    예: 보고서 창에서 인쇄/PDF·HTML·MD·TXT 중 하나를 고르고 [저장]을 누릅니다.
    선택만 바꿔서는 인쇄·다운로드가 시작되지 않습니다(키보드 화살표로도 안전).
  - 보고·제출 → 기존 예산 보고 도구: [보고서] 목록에서 전체 보고서·기관장 브리핑·
    예상질의 참고·자동 점검 후보 중 하나를 고르고 [열기]를 누릅니다.
    의회 보고 표(Markdown)는 바로 내려받는 버튼으로 그대로 둡니다.
  - 세부 예산항목의 필터 18개는 [대상] 선택 목록 하나로 모았습니다(아래 [필터] 참고).
  - 다크 모드에서 인쇄해도 밝은 배경으로 출력됩니다(이전에는 어둡게 나오던 문제 수정).
  - 내려받는 파일(보고서·브리핑·예상질의·감사진단·XLSX 등)의 내용은 바뀌지 않았습니다.

[2026-11-12 실행기 창 하나로 입력]

  - 실행하면 창 하나에 원본 파일·기관명·자료 기준일·이전 시점 원본·월별 이력 폴더가
    함께 나옵니다. 예전처럼 대화상자 다섯 개가 차례로 뜨지 않습니다.
  - 기관명과 월별 이력 폴더는 직전 값이 채워져 있습니다. 원본 파일 선택 창은 직전 폴더에서 열립니다.
  - 자료 기준일은 원본 파일명에 날짜가 있으면 미리 채워집니다. 실제 기준일과 다르면 고치거나
    비워 두세요(비우면 '자료 기준일 미확인'). 직접 고친 날짜는 다른 파일을 골라도 유지됩니다.
  - 이전 시점 원본과 월별 이력 폴더는 필요할 때만 고르고, '지우기'로 비울 수 있습니다.
  - '대시보드 만들기'를 누르면 원본과 같은 폴더에 파일을 만들고 브라우저로 엽니다. 창은 닫히지 않으므로
    다른 원본으로 바로 다시 만들 수 있습니다. 결과와 오류(엑셀 파일 열림 등)는 창 아래에 표시됩니다.
  - 예산현액 엑셀 파일을 실행 파일 아이콘에 끌어다 놓으면 원본 칸이 채워진 채로 창이 열립니다.
    창 안으로 끌어다 놓는 기능은 없습니다. '찾아보기'를 쓰세요.

[2026-10-08 검산 확대 · 저장/복구 · 연말 집행계획]

  적용 대상: v10.0.1 EXE, 현재 Python 생성기와 budget_dashboard.html. 기존 ver9 EXE는 보존했습니다.

  1. 총괄 현황 → 원본 검산
     예산현액 등 11개 열을 전체 및 목별로 대조합니다. 일치/불일치/미확인을 구분하며,
     미확인 금액은 0원으로 처리하지 않습니다. 범위 선택과 '확인 필요만' 필터를 지원합니다.
     '검산표 내려받기'는 모든 범위의 결과를 원 단위 CSV로 저장합니다.

  2. 자료관리·설정 → 업무 기록 저장·복구
     조치, 메모, 집행유형, 행감, 재원, 결산·성과의 저장된 기록 6종을 JSON 하나로 백업합니다.
     복원 파일을 고르면 기관·내용과 건수를 확인한 뒤 적용합니다. 이전 백업에 빠진 메모와
     집행유형은 유지하며, 포함된 빈 목록은 비웁니다. 원본 XLSX는 백업에 포함되지 않습니다.
     적용 직후 '되돌리기'를 쓸 수 있습니다. 이후 기록이 수정되면 되돌리기는 중단됩니다.
     다른 창에서 변경한 경우 저장을 차단합니다. 미저장 입력을 확인하고 최신 상태를 다시 읽으세요.
     저장 실패 시 입력을 유지합니다. 복구에도 실패하면 보호 상태와 복구자료 받기를 제공합니다.

  3. 총괄 현황 또는 재원·집행 → 연말 집행계획
     남은 잔액을 지급 대기와 원인행위 필요액으로 나누어 다음 조치를 확인합니다.
     0원 예산의 지출, 음수, 금액 관계·원본 결측 문제는 '금액 확인'에 남습니다.
     월평균 필요액은 자료 기준일이 확인된 경우에만 산정하며, 전체 검산이 미완료면 총계는 보류합니다.
     계획 검토일 변경은 자료 기준일을 확정하는 기능이 아닙니다.
     검색·사업·상태 필터를 적용한 표를 CSV 또는 인쇄용 보고서로 열 수 있습니다.
     항목 이름을 누르면 해당 예산의 상세표로 이동합니다.

  화면: 일반/다크 색상, 숫자 위계, 모바일 헤더를 정리했습니다. 모바일 표는 좌우로 밀어 보세요.
  현재 원본은 기관·자료 기준일 미확인입니다. 실제 값을 확인한 뒤 --org, --source-as-of로 재생성하세요.

[2026-09-09 행감 작업공간 · Clear Glass 02]

  새 화면: 총괄 현황 / 재원·집행 / 행감 준비 / 증빙·조치 / 보고·제출.
  Python 생성기·단일 HTML과 이번 배포 EXE에 새 화면을 적용했습니다.
  이전 ver8 EXE로 생성한 HTML에는 새 기능이 없으므로 최신 EXE로 재생성하세요.
  예산현액과 지급액·잔액은 첫 화면에서 확인하고, 사업별 요약은 예산 큰 순입니다.

  Python 실행 예:
    python run_budget_dashboard.py -i "예산현액.xlsx" --no-open
  EXE 명령줄 실행 예:
    "budget-dashboard.exe" -i "예산현액.xlsx" --no-open
  실제 기관명·원본 집행자료 기준일을 알고 있을 때만 추가:
    --org "확인한 기관명" --source-as-of YYYY-MM-DD

[5단계 고도화 상세 화면 사용법]

  - 세부 화면에서는 상단 신뢰도·관제 요약이 자동으로 축약되어 표가 빠르게 보입니다.

  - 기본 표는 행감 대사에 필요한 핵심 8열을 표시합니다. 기존 저장 열 설정은 유지합니다.

    안에서 고정되어 열 제목을 잃지 않습니다.

    주기적으로 백업하는 것을 권장합니다.

  - 개요 화면 '점검 요약'의 집행 점검·기준 확인·한도 초과 카드를 누르면
    해당 항목 목록으로 바로 이동합니다('오늘의 작업 목록'과 동일).
  - [사용설명서] 버튼: 화면 흐름과 각 기능 사용법을 화면 안에서 봅니다.
  - [용어 풀이] 버튼: 예산현액·원인행위·일상경비·재배정·이전지출·특교·
    불용·이월·산출기초 등 핵심 용어 정의를 봅니다.

[명령줄 옵션 - 고급]

  python run_budget_dashboard.py 실행 시 다음 옵션을 쓸 수 있습니다.
    -i, --input   예산현액.xlsx 경로
    -o, --output  생성할 HTML 경로
    -c, --compare 이전 시점 예산현액.xlsx (시점 비교 활성화)
    --org         기관명(예상질의 각주·파일명)
    --report-unknown-codes
                  기준(budget_rules.json) 미등록 비목코드를 집계해 출력합니다.
                  어떤 원가통계비목에 기준을 추가할지 점검할 때 사용합니다.
    --emit-md DIR 예상질의답변·감사대비진단을 Markdown 파일로 DIR에 저장합니다.
                  저장된 .md 는 to_hwpx_com.py 로 HWPX 변환할 수 있습니다.
                  예) python run_budget_dashboard.py -i 예산현액.xlsx \
                        --emit-md 보고서출력 --org "학생교육원"
    --next-budget 요구서.xlsx
                  차기연도 본예산 세출예산요구서(당해 본예산·차기 요구액이 함께 있는 파일 1개)로
                  변동표, 주요 증감 사유 점검·표현 수정 제안, 시의회 예상질의 목록(질문과 근거만)을
                  HTML·MD·TXT로 만듭니다. 비교 기준은 당해 본예산 편성액 ↔ 차기 요구액(조정액 열 미사용).
                  HTML 위쪽 [범위]·[형식] 선택 후 [복사] 또는 [파일로 저장]으로 전체·변동표·사유 점검·
                  예상질의·설명서 대조를 텍스트(□·○·- 기호, 표는 탭 구분 — 한글·엑셀 붙여넣기용)나
                  Markdown으로 옮길 수 있습니다.
    --project-desc 설명서.hwpx
                  --next-budget 과 함께: 세부사업설명서의 '주요증감사유'를 요구서와 줄 단위로 대조(여러 번 지정 가능).
                  예) python run_budget_dashboard.py --next-budget 세출예산요구서.xlsx \
                        --project-desc 세부사업설명서.hwpx --org "학생교육원" -o 본예산_변동분석.html
                  -i 예산현액.xlsx 를 함께 주면 원래 대시보드(집행 분석·잔여 예산·보고서)도 그대로 만들고,
                  본예산 변동 분석은 대시보드와 같은 폴더에 '본예산_변동분석_날짜.html'로 만들며 서로 링크합니다.
                  이때 -o 는 대시보드 경로입니다.
                  예) python run_budget_dashboard.py -i 예산현액.xlsx -o budget_dashboard.html \
                        --next-budget 세출예산요구서.xlsx --project-desc 세부사업설명서.hwpx
                  표현 규칙·질의 규칙은 reference/budget_yoy_rules.json(선택)으로 바꿀 수 있습니다
                  (wording·questions 목록을 통째로 교체, 형식은 budget_yoy.py 의 DEFAULT_RULES).

[예산편성 기준(budget_rules.json) 관리]

  - reference/budget_rules.json 의 비목코드별 기준으로 산출기초 단가를 검증합니다.
  - 정액 단가가 없는 항목(계약·실비·견적·교부·정산 성격)은 "확인"으로 표시하며,
    임의 한도를 만들지 않습니다.
  - 미등록 코드는 --report-unknown-codes 로 확인 후, 공식 예산편성 기본지침에
    근거해 기준을 추가하세요.

[참고]

- 엑셀 파일이 열려 있으면 오류가 발생할 수 있습니다. 파일을 닫고 실행하세요.
- 예산현액 표준 양식이 아닌 파일(다른 조회 화면에서 받은 엑셀 등)을 선택하면
  "이 파일은 예산현액 표준 양식이 아닙니다" 안내가 뜨고 대시보드가 생성되지
  않습니다. K-에듀파인에서 예산현액(일상경비포함 체크) 양식으로 다시
  내려받아 주세요.
- budget_dashboard.html 은 인터넷 연결 없이도 동작합니다.
- 데이터가 바뀔 때마다 exe 를 다시 실행하면 최신 현황이 반영됩니다.
- GUI 출력 파일명에는 생성일이 붙습니다(budget_dashboard_YYYY-MM-DD.html).
  이는 원본 집행자료 기준일이 아닙니다. 같은 날 재생성할 때 기존 산출물 보존이
  필요하면 먼저 다른 이름으로 보관하거나 명령줄 -o 옵션으로 별도 경로를 지정하세요.
- 마지막 기관명·폴더는 내 PC 사용자 폴더의 .budget_dashboard_settings.json
  에 저장됩니다(개인정보 아님, 삭제해도 다음 실행 시 새로 생성됩니다).
