예산 집행 현황 대시보드 - 사용 방법
=============================================

[전체 흐름]

  1. 예산현액.xlsx   ← 예산시스템(재정사업관리->예산관리->예산편성->사업관리카드-> 회계연도 선택 ->예산현액(일상경비포함 체크) -> 파일 내려받기) 에서 내려받은 원본 파일(별도 가공 필요 없음)
           ↓
  2.대시보드_실행.exe 더블클릭
    → 파일 선택 창: 예산현액.xlsx 선택 (직전 실행 폴더가 기본으로 열립니다)
    → 기관명 입력 (직전 입력값이 기본으로 채워집니다)
    → "이전 시점 파일과 비교하시겠습니까?" 확인 — 예 선택 시 비교할
      이전 예산현액.xlsx를 추가로 선택(추경 전후·월중 비교용, 생략 가능)
           ↓
  budget_dashboard_YYYY-MM-DD.html 생성(기준일 자동 부여, 이전 산출물 보존)
  → 브라우저 자동 오픈 → 집행 현황 시각화
  사업별 xlsx 파일로 다운로드 가능

[파일 구성]

 exe 파일 실행      ← 실행 파일 (더블클릭)

 

[화면 구성 - 3단계 드릴다운]

  1단계: 개요
    - KPI 카드: 총 예산현액 / 원인행위액 / 지출액 / 일상경비 교부액 / 기준 확인 항목 / 한도 초과 의심 / 이월액 / 사업비 집행률
    - 사업별 카드: 사업명, 예산 요약, 단위사업·운영유형·세부항목 수, 목 그룹 태그

  2단계: 사업 클릭 → 단위사업별 현황
    - 해당 사업의 단위사업 카드 목록
    - 각 단위사업별 예산현액·원인행위율·지출률·운영유형·기준확인 건수 표시
    - [사업 XLSX 다운로드] 버튼으로 해당 사업의 전체 세부항목을 엑셀 파일로 저장

  3단계: 단위사업 클릭 → 세부 예산항목 테이블
    - 목 그룹, 운영유형, 세부경로, 예산항목, 5자리 코드, 원가통계비목, 산출기초
    - 추출단가, 기준한도, 근거쪽, 검증상태(적정/확인/초과)
    - 예산현액, 원인행위액, 지출액, 일상경비 교부액·지출액·잔액, 등급, 점검메모
    - [단위사업 XLSX 다운로드] 버튼으로 현재 단위사업 세부항목만 엑셀 파일로 저장

[5단계 고도화 상세 화면 사용법]

  - 세부 화면에서는 상단 신뢰도·관제 요약이 자동으로 축약되어 표가 빠르게 보입니다.
  - 우측 "선택 항목 조치" 패널은 처음에는 닫혀 있습니다. 표의 행을 클릭하거나
    키보드로 행에 이동한 뒤 Enter/Space를 누르면 열립니다. Esc를 누르면 닫히고
    포커스가 원래 행으로 돌아갑니다.
  - 기본 표는 집행 점검에 필요한 12열만 표시합니다.
      사업명 / 단위사업 / 예산항목 / 집행유형 / 예산현액 / 실제 원인행위액 /
      원인행위율 / 실제 지출액 / 지출률 / 위험유형 / 등급 / 점검메모
  - 표 위의 컬럼 프리셋을 목적에 맞게 선택합니다.
      [집행 점검] 집행액·집행률·위험·메모 중심 12열(기본)
      [기준 검증] 비목코드·산출기초·단가·한도·근거·검증 중심 12열
      [교부 관리] 집행액과 배부액·교부액·교부잔액 중심 12열
      [전체] 모든 26열
    [컬럼 관리]에서 직접 고른 기존 열 설정은 삭제하지 않고 계속 사용할 수 있습니다.
  - 열이 화면보다 넓으면 표 영역 안에서만 좌우로 스크롤합니다. 모바일에서는
    조치 패널이 화면 오른쪽 전체 높이로 열리며, 닫을 때까지 본문 스크롤이 잠깁니다.
  - 0건인 필터는 흐리게 표시되고 눌리지 않습니다.
  - "오늘의 작업 목록"의 "고유 항목"은 조건 간 중복을 제거한 수입니다.
    "카드 합계 · 유형별 중복 포함"은 한 항목이 여러 업무 유형 카드에 포함된
    횟수까지 합한 수이므로 두 값이 서로 다를 수 있습니다.
  - 사업·단위사업 카드는 Tab으로 이동하고 Enter/Space로 상세 화면을 열 수 있습니다.
  - 상단 [다크]/[라이트] 버튼으로 테마를 바꿀 수 있으며 선택은 같은 브라우저에
    저장됩니다.

[예산편성 기준 반영 내용]

  - 원가통계비목 7자리 코드에서 앞 5자리 코드를 자동 표시합니다.
    예: [2100605] 강사수당 → 21006 운영수당
  - reference/budget_rules.json 기준표를 우선 반영합니다.
  - 기준표가 없거나 exe만 단독 실행하는 경우에도 기본 내장 기준을 사용합니다.
  - 산출기초의 첫 금액(예: 50,000원×3명×3시간)을 추출단가로 읽어 한도와 비교합니다.
  - 정액 한도가 아닌 계약·실비·견적 기준 항목은 "확인"으로 표시합니다.
  - PDF 원본: reference/2026 인천광역시 교육비특별회계 예산편성 기본지침.pdf

[원본 구조 반영 내용]

  - 예산현액.xlsx 한 파일만 사용합니다.
  - [210] 운영비, [220] 여비, [230] 업무추진비, [430] 유형자산 등 목 그룹을 보존합니다.
  - 동일 사업명이 여러 목 그룹에 반복되어도 사업별로 합산하고, 세부항목에는 목 그룹을 표시합니다.
  - 운영유형 아래의 가), (1), (가) 같은 하위 산출 경로도 세부경로로 보존합니다.
  - 이전 자료와 비교하고 싶다면 별도 폴더를 만들어서 html, xlsx 파일을 저장하는 것도 방법입니다.

[등급 기준]

  주의  : 원인행위 0원, 원인행위잔액 음수, 일상경비 교부잔액 음수
  관찰  : 원인행위율 30% 미만, 또는 원인행위 있으나 지출 0원
  정상  : 위 조건 해당 없음

[기준 검증 상태]

  적정  : 추출단가가 기준한도 이하
  확인  : 정액 한도가 없거나 세부 기준 확인이 필요한 항목
  초과  : 추출단가가 기준한도를 초과한 것으로 의심되는 항목

  검증 메모에 다음 표시가 추가로 붙을 수 있습니다(산출기초 검증 2.0):
    산출근거 불명(총액계상 의심)      : 산출기초가 비어 있는 고액 항목(500만원↑)
    산출기초 계산 불일치(단가×수량 ≠ 예산현액) : 산출기초의 곱셈식(단가×수량×횟수)이
      예산현액과 5% 넘게 차이 나는 항목. [추경N] 재게재는 무시하고 계산하며,
      [변경사용감/증] 같은 가감 라벨은 아직 인식하지 못해 오탐 가능 — 표시되면
      먼저 육안으로 산출기초 원문을 확인하세요.

[목표 집행률 대비 갭 · 경과율 기준선]

  - 대시보드 상단 "실제 지출률" 아래에 "목표 대비 ±N%p (목표 M%)"가 표시됩니다.
    달력 경과율이 아니라 본청이 쓰는 신속집행 목표 집행률(3월 25%·6월 57%·
    9월 80%·12월 100%, 월 사이는 선형 보간) 기준입니다.
  - reference/risk_config.json의 execution_targets에서 조정합니다. 기본값은
    일반적인 관행을 반영한 참고치이며 확정 수치가 아니므로, 매년 본청 공문
    수치로 갱신하세요.
  - 진행바(지출률)에는 연도 경과율 지점에 세로선(기준선)이 표시되어, 선보다
    왼쪽에 있는 막대는 부진, 오른쪽은 앞서감을 한눈에 볼 수 있습니다.

[세출목그룹별 집행 구조 - 경직성·사업성]

  - 개요 화면 하단에 "세출목그룹별 집행 구조" 표가 추가됐습니다. 비목코드
    5자리의 첫 자리로 진짜 세출목그룹(100번대 인건비~700번대 예비비 및 기타)을
    구분해 그룹별 집행률을 보여줍니다. 기존 KPI의 "목 그룹"(예: [210] 운영비)은
    더 세분된 "목" 표기이며, 이 표의 "OOO번대"가 상위 목그룹입니다.
  - 인건비·상환지출·예비비(경직성 경비)는 예산 성격상 집행률이 자연히 높아
    전체 집행률을 부풀립니다. "사업비 집행률" KPI는 이 경직성 경비를 제외한
    순수 사업비만의 집행률로, 행감·결산에서 더 의미 있는 지표입니다.
  - 경직성/사업성 기본 분류는 목그룹 코드로 정해지며, 특정 세목만 다르게
    분류하려면 reference/budget_rules.json 해당 항목에 "rigidity": "경직성"
    또는 "사업성"을 추가하면 우선 적용됩니다.

[강사수당 등급별 상한 - 산출기초 검증 2.0]

  - 강사수당(21006) 검증이 등급별로 세분화됐습니다(2026 기본지침 p.51~52 근거).
      특별강사1 기본 300,000원 / 초과 200,000원
      특별강사2 기본 200,000원 / 초과 150,000원 (특별강사 키워드는 1급 기준 적용,
        2급이면 산출기초·항목명에 등급을 명시해 별도 확인)
      일반강사1 기본 160,000원 / 초과 90,000원
      일반강사2 기본 90,000원 / 초과 60,000원
      기타(외국어·체육·전산 등) 50,000원 / 실기실습보조·원어민보조교사 40,000원
  - 항목명·세부경로에 "일반강사2", "특별강사", "원어민보조" 등 등급 키워드가
    있어야 해당 등급 기준으로 검증됩니다. 등급 표기가 없으면 기존처럼 1급
    기준(기본 160,000/초과 90,000)으로 검증합니다.
  - 간식비(21012 하위)는 5,000원/인 단일 기준으로 검증됩니다.
  - 급량비(21004)·기관운영업무추진비(23001)는 지침상 단일 정액 단가가 없어
    (급량비는 구성 항목별 실소요, 기관운영업추비는 기관 전체 연간 총액의
    0.12% 등) 임의 한도를 만들지 않고 "확인" 대상으로 문서화만 했습니다.

[가독성 개선]

  - 본문·표·KPI 폰트 크기를 확대했습니다.
  - 저시력자도 읽기 쉽도록 배경 대비와 행 간격을 키웠습니다.
  - 기존 3단계 드릴다운 구조는 유지했습니다.

[화면 모드 - 라이트/다크 전환]

  - 화면 우측 상단 [🌙 다크] 버튼을 누르면 어두운 배경 화면으로 전환됩니다
    (다시 누르면 [☀️ 라이트]로 되돌아옵니다).
  - 선택한 모드는 브라우저에 저장되어 다음에 파일을 열어도 그대로 유지됩니다.
  - [인쇄/PDF 저장]·보고서 인쇄는 다크 모드에서도 항상 밝은 배경으로 출력됩니다.

[세부 예산항목 표 - 정렬·컬럼 관리]

  - 표 헤더(사업명·예산현액·지출률 등)를 클릭하면 해당 컬럼 기준으로
    오름차순/내림차순 정렬됩니다(다시 클릭하면 방향 전환, ▲▼ 표시).
  - 헤더는 Tab 키로 이동해 Enter·스페이스로도 정렬할 수 있습니다.
  - 표 위 [컬럼 관리] 버튼을 누르면 26개 컬럼을 개별로 켜고 끌 수
    있습니다(예: 근거·검증 컬럼을 숨기고 화면에 집중). 표시/숨김
    설정은 브라우저에 저장되어 다음에 열 때도 유지됩니다.
  - 사업명·첫 컬럼과 표 헤더는 스크롤해도 항상 보이도록 고정됩니다.

[필터 - 그룹화·건수 배지]

  - 세부항목 필터가 "집행 상태"(전체·집행 점검·지출 0원 등)와
    "기준 검증"(기준 확인·초과 의심·특교·이슈) 두 줄로 나뉘고,
    "위험 유형"(오류의심·초과의심 등 6종)은 [위험 유형 ▾] 버튼을
    눌러야 펼쳐지는 접힘 구조입니다.
  - 각 필터 버튼에 현재 목록 기준 건수가 배지로 표시되며, 0건인
    필터는 흐리게 비활성화됩니다.

[키보드·화면읽기 접근성]

  - 모든 팝업(메모·계산기·보고서·설명서 등)은 Esc 키로 닫을 수
    있고, 닫으면 팝업을 열었던 버튼으로 포커스가 되돌아갑니다.
  - 팝업이 열려 있는 동안 Tab 키는 팝업 안의 버튼·입력란 사이에서만
    순환합니다(포커스 트랩).

[알림(토스트)·검색 반응 속도]

  - 메모 저장·삭제, 조치 내보내기/가져오기 결과가 화면 하단에
    잠깐 나타나는 알림(토스트)으로 표시됩니다(팝업 차단 없음).
  - 세부항목 검색창은 입력을 멈춘 뒤 짧게 반응해(0.25초) 항목이
    많아도 타이핑이 끊기지 않습니다.
  - 조건에 맞는 항목이 없을 때 표에 [필터 초기화] 버튼이 함께
    표시됩니다.
  - Ctrl+P로 화면을 바로 인쇄하면 "전체 보고서" 버튼을 쓰라는
    안내가 나타납니다(실제 인쇄물은 보고서 팝업 기준으로 구성됨).

[엑셀 다운로드]

  - 사업 상세 화면: 사업 전체 예산항목을 .xlsx 파일로 다운로드합니다.
  - 단위사업 상세 화면: 현재 단위사업 예산항목만 .xlsx 파일로 다운로드합니다.
  - 다운로드 파일에는 화면의 주요 컬럼과 기준 검증 컬럼이 함께 포함됩니다.
  - 인터넷 연결이나 별도 엑셀 라이브러리 없이 HTML 내부 기능으로 생성됩니다.

[예상질의 생성 - 주요예산사업보고 대비]

  - 개요 화면의 [예상질의 생성] 버튼을 누르면 단위사업별
    "주요예산사업보고 예상질의 답변" 문서가 자동 생성됩니다.
  - 질의 유형은 데이터 상황으로 자동 선택됩니다(우선순위 순, 7종).
      회계오류(잔액 음수)   : "예산현액 대비 초과 집행 사유는?"
      미착수(지출 0원)      : "집행되지 않은 사유와 향후 추진 계획은?"
      부진(경과율 대비 지연): "집행이 부진한 사유와 대책은?"
      변경사유(추경·전용, 시점 비교 입력 시): "당초 예산 대비 증액/감액 사유는?"
      잔액처리(연말 임박·고집행률·잔액 상당): "집행잔액 처리 계획(불용 우려 포함)은?"
      특교종료(특별교부금 사업)             : "특별교부금 종료 이후 지속 추진 방안은?"
      정상                                   : "예산 확보 및 집행 현황은?"
  - 미착수 등 답변 요지는 "문제 없음"처럼 근거 없이 단정하지 않고
    (작성)으로 실제 사유 확인을 유도합니다.
  - 답변 요지·예산현황 표·핵심답변은 자동 산출되고,
    (작성) 표시 부분만 담당자가 사업 내용으로 채우면 됩니다.
  - [인쇄/PDF 저장], [MD 저장], [텍스트 복사]를 지원합니다.

[감사 대비 진단 - 행정사무감사 대비]

  - 개요 화면의 [감사 대비 진단] 버튼을 누르면 "지적 예상 N건" 스탬프와
    함께 8개 진단으로 분류합니다. 한 항목은 가장 심각한 진단 하나에만
    배정됩니다(중복 없음).
      ① 집행 초과·잔액 음수(금액 무관) ② 장기 미착수(100만원↑)
      ③ 위탁·이전 지연 ④ 집행 부진(300만원↑, 경과율 -20%p)
      ⑤ 연말 집중집행 위험(9월 이후 — 행정사무감사 역산 대응 시간 확보) ⑥ 교부·재배정 잔액 방치(6월 이후,
        일상경비 교부 또는 재배정 수령분 절반 이상 미집행)
      ⑦ 불용 예상(실질 경과월 기준 페이스 추정, 원인행위 확정분은
        하한으로 반영해 과대추정을 방지 — 위탁·이전 비목은 일시지출
        특성상 제외)
      ⑧ 이월예산 미집행(이월액 100만원↑ 인데 지출률 30% 미만 — 재이월·
        불용 위험)
  - 금액 하한·시작월은 reference/risk_config.json 의 audit 섹션에서
    기관 사정에 맞게 조정할 수 있습니다.
  - 진단 항목의 [조치 등록] 버튼을 누르면 해당 세부항목 화면으로 이동해
    조치상태·담당부서·회신기한을 바로 입력할 수 있습니다.
  - [진단 목록(XLSX)] 버튼은 진단 결과와 조치 상태를 함께 내려받습니다.
  - [지적사항 처리계획서(MD)] 버튼은 진단 항목을 1건 1서식(현황→지적요지→
    소명→조치계획→완료예정일)으로 정리한 Markdown을 내려받습니다. 수치는
    자동, 소명·조치계획·완료예정일은 (작성)으로 남아 담당자가 채웁니다.

[요약 브리핑 - 원장·의회 보고 첫 장]

  - 개요 화면의 [요약 브리핑] 버튼을 누르면 A4 1쪽 분량으로
    핵심 지표 3줄 → 점검 필요 사업 Top 5(사유 1줄씩) → 조치 진행 현황
    → 향후 계획(작성) 순의 요약이 생성됩니다.
  - 조치 진행 현황은 브라우저에 저장된 실제 조치 데이터를 반영합니다.
  - [인쇄/PDF 저장], [MD 저장]을 지원하며, 결재 문서에 그대로 첨부할 수
    있는 분량입니다.

[조치 폐쇄 루프 - 이력·종결근거·기한 도과]

  - 사이드바 조치상태를 변경하면 변경 이력(일시·이전상태→새상태)이
    자동 기록되고 "변경 이력" 목록에 표시됩니다.
  - "종결근거" 입력란에 완료 처리 시 회신 문서번호·일자를 기록해 두면
    나중에 "언제 무엇으로 종결했는지"를 바로 확인할 수 있습니다.
  - 회신기한이 지났는데 상태가 완료·보류가 아니면 사이드바에 "기한 도과"
    배지가 표시되고, 화면 상단에 "회신기한 도과 N건" 안내 배너가 나타납니다.
  - [조치 목록(XLSX)]에 종결근거·최근 변경 이력·기한도과 여부 컬럼이
    추가로 포함됩니다.

[시점 비교 - 추경 전후·월중 비교]

  - 명령줄에서 이전 시점 파일을 함께 지정하면 [시점 비교] 버튼이 생깁니다.
      python run_budget_dashboard.py -i 현재.xlsx -c 이전.xlsx
  - 지출 변동(증감 큰 순), 예산현액 변동(추경·전용 확인), 신규·제외
    항목을 보여줍니다. 행 위치가 밀려도 사업·경로·비목 기준으로 매칭합니다.

[특교(특별교부금) 표시]

  - 사업·단위·비목 명칭에 "특교" 또는 "특별교부"가 포함된 항목은 세부항목
    표의 사업명 옆에 [특교] 배지로 표시됩니다.
  - 세부항목 필터의 [특교] 버튼으로 특교 사업만 모아볼 수 있습니다.
  - 예상질의 답변에도 특교 사업은 자체 예산 확보 방안 각주가 자동 추가됩니다.

[이월액·배정잔액 KPI]

  - 개요 화면 KPI에 "이월액"(하위: 배정잔액) 카드가 추가됐습니다.
  - 예산현액.xlsx에서 읽은 배정액·배정잔액·이월액을 세부항목·KPI에
    반영합니다. 이월액이 있는데 지출률이 낮은 항목은 감사 대비 진단의
    ⑧ 이월예산 미집행 버킷에서 별도로 확인할 수 있습니다.

[조치·메모 데이터 유지 - 매월 재실행해도 유지]

  - 조치(담당부서·회신기한·상태)·메모·유형변경 데이터는 브라우저
    localStorage에 저장되며, 저장 위치(네임스페이스)는 파일명이 아닌
    기관명(--org 입력값) 기준입니다. 매월 새 예산현액.xlsx로 다시
    생성해도 같은 브라우저에서 열면 조치 데이터가 그대로 유지됩니다.
  - 항목 식별도 엑셀 행 번호가 아닌 "사업·단위사업·경로·비목코드"
    기준으로 바뀌어, 재배정·추경으로 행 위치가 밀려도 조치 기록이
    끊기지 않습니다.
  - 예전 버전(파일명 기준)으로 저장해 둔 조치 데이터가 있으면 새
    버전으로 열 때 자동으로 1회 이관됩니다(기존 데이터는 삭제하지
    않고 그대로 둡니다).
  - 사이드바에서 조치를 입력하면 "저장됨 ✓" 표시가 잠깐 나타나
    저장 여부를 바로 확인할 수 있습니다.
  - 그래도 담당자 교체·PC 변경에 대비해 [조치 내보내기(JSON)]로
    주기적으로 백업하는 것을 권장합니다.

[빠른 이동 · 도움말]

  - 개요 화면 '점검 요약'의 집행 점검·기준 확인·한도 초과 카드를 누르면
    해당 항목 목록으로 바로 이동합니다('오늘의 작업 목록'과 동일).
  - [사용설명서] 버튼: 화면 흐름과 각 기능 사용법을 화면 안에서 봅니다.
  - [용어 풀이] 버튼: 예산현액·원인행위·일상경비·재배정·이전지출·특교·
    불용·이월·산출기초 등 핵심 용어 정의를 봅니다.

[명령줄 옵션 - 고급]

  python run_budget_dashboard.py 실행 시 다음 옵션을 쓸 수 있습니다.
    -i, --input   예산현액.xlsx 경로
    -o, --output  생성할 HTML 경로
    -c, --compare 이전 시점 예산현액.xlsx (시점 비교 활성화)
    --org         기관명(예상질의 각주·파일명)
    --report-unknown-codes
                  기준(budget_rules.json) 미등록 비목코드를 집계해 출력합니다.
                  어떤 원가통계비목에 기준을 추가할지 점검할 때 사용합니다.
    --emit-md DIR 예상질의답변·감사대비진단을 Markdown 파일로 DIR에 저장합니다.
                  저장된 .md 는 to_hwpx_com.py 로 HWPX 변환할 수 있습니다.
                  예) python run_budget_dashboard.py -i 예산현액.xlsx \
                        --emit-md 보고서출력 --org "학생교육원"

[예산편성 기준(budget_rules.json) 관리]

  - reference/budget_rules.json 의 비목코드별 기준으로 산출기초 단가를 검증합니다.
  - 정액 단가가 없는 항목(계약·실비·견적·교부·정산 성격)은 "확인"으로 표시하며,
    임의 한도를 만들지 않습니다.
  - 미등록 코드는 --report-unknown-codes 로 확인 후, 공식 예산편성 기본지침에
    근거해 기준을 추가하세요.

[참고]

- 엑셀 파일이 열려 있으면 오류가 발생할 수 있습니다. 파일을 닫고 실행하세요.
- 예산현액 표준 양식이 아닌 파일(다른 조회 화면에서 받은 엑셀 등)을 선택하면
  "이 파일은 예산현액 표준 양식이 아닙니다" 안내가 뜨고 대시보드가 생성되지
  않습니다. K-에듀파인에서 예산현액(일상경비포함 체크) 양식으로 다시
  내려받아 주세요.
- budget_dashboard.html 은 인터넷 연결 없이도 동작합니다.
- 데이터가 바뀔 때마다 exe 를 다시 실행하면 최신 현황이 반영됩니다.

  지난달 산출물이 덮어써지지 않고 폴더에 그대로 남습니다.
- 마지막 기관명·폴더는 내 PC 사용자 폴더의 .budget_dashboard_settings.json
  에 저장됩니다(개인정보 아님, 삭제해도 다음 실행 시 새로 생성됩니다).
