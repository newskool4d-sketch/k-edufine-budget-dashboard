# v10.2.1 — 예산 수치·업무 기록·업데이트 안정성 수정

- 혼합 집행자료에서 실제 집행액을 확정할 수 없으면 원본 행과 금액을 안내하고 생성을 중단합니다. 기존 원본과 보고서를 보존합니다.
- 중복 항목의 기록·재원 오연결을 차단했습니다. 이전 기록은 원문을 보존하며 담당자가 확인 후 연결합니다. 이전 파일명 저장 영역은 별도 원문 백업을 이용하세요.
- 연말 필요액, 수동 집행유형 변경 후 요약 수치, 예산 구성비, 보고서 누락 건수와 내보내기를 수정했습니다.
- 산출기초 계산기의 연산자·단위·이력 보존, 본예산 시트·날짜·동명 사업의 모호성 처리, 설정·오류 안내를 보완했습니다.
- 업데이트 준비 중 취소와 창 닫기 경합 시 시험 대상 임시 파일을 정리합니다.

## 설치
`budget-dashboard-v10.2.1.zip`을 새 폴더에 풀고 `budget-dashboard.exe`를 실행하세요. 기존 자동 업데이트 지원 버전은 실행 시 새 버전을 안내합니다.
업데이트 전 기존 업무 기록을 백업하세요. 실행 파일은 코드 서명되지 않았습니다.

## 검증 범위
자동 테스트 1,019개 통과·선택 자료 미존재 2개 제외. 실제 Chromium·Python/EXE 출력 일치·격리 환경의 실제 업데이트 창/설치/백업/재시작 검증 통과(133.45초). 최종 검사 수치와 자산 해시는 함께 제공하는 검증 문서 및 SHA256SUMS.txt를 참고하세요.
실제 회계 원본과 Excel 앱 직접 열기는 이번 검증에 포함하지 않았습니다. 실제 업데이트 교체 시험은 로컬 전송을 사용한 QA 구버전에서 수행하며 과거 모든 릴리스와의 호환성을 뜻하지 않습니다.

예산 XLSX·생성 대시보드·사용자 업무 기록은 배포 파일에 포함하지 않습니다.
