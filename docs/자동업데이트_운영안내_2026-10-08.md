# 자동 업데이트 안내

대상: 예산 집행 현황 대시보드 Windows EXE v10.0.0 이상.

## 처음 설치할 때

기존 ver9에는 자동 업데이트 기능이 없습니다. [정식 릴리스](https://github.com/newskool4d-sketch/k-edufine-budget-dashboard/releases/latest)에서 v10 ZIP을 내려받아 새 폴더에 압축을 풀고 `2.대시보드_실행.exe`를 실행하세요. 새 예산서가 없어도 프로그램을 받아 둘 수 있으며, 엑셀 선택 창에서 취소하면 종료됩니다.

기존 HTML에 새 기능이 자동 반영되지는 않습니다. 새 EXE로 다시 생성하세요. 이동·재생성 전에 기존 화면의 자료관리·설정에서 업무 기록을 JSON으로 백업하고, 새 화면에서 복원 결과를 확인하세요.

## 다음 버전부터

1. EXE를 실행하면 새 정식 릴리스를 자동 확인합니다.
2. 새 버전이 있으면 현재·새 버전과 **업데이트 / 나중에** 버튼이 나타납니다.
3. **업데이트**를 누르면 파일 크기·SHA-256·실행 파일 형식을 검증합니다.
4. 현재 프로그램 종료 후 같은 경로의 EXE를 교체하고 재실행합니다. 사용자가 변경한 실행 파일 이름도 유지합니다.
5. 기존 EXE는 같은 폴더의 `*.previous-<고유값>.exe`로 보관합니다.

**확인 건너뛰기** 또는 **나중에**를 누르면 현재 버전으로 계속 작업합니다. 인터넷이 끊기거나 릴리스가 없어도 사용할 수 있습니다. 확인 창은 최대 8초 뒤 현재 버전 사용으로 넘어갑니다. 취소 후 늦게 끝난 다운로드로 교체를 예약하지 않습니다.

## 보존되는 자료

업데이트는 EXE만 교체합니다. 예산 XLSX, 이미 생성한 HTML, 브라우저 업무 기록, 사용자 설정, 외부 `reference/` 기준은 덮어쓰지 않습니다. 새 ZIP의 기준 파일을 기존 기관별 기준 위에 직접 복사하는 경우에는 기존 기준을 먼저 보관하고 비교하세요.

브라우저·PC·파일 경로 변경 시에는 업무 기록이 자동 이관된다고 가정하지 말고 JSON 백업·복원으로 확인하세요. 원본 XLSX와 저장 전 입력은 업무 기록 백업에 포함되지 않습니다.

## 실패하면

검증에 실패한 파일은 적용하지 않습니다. 교체 또는 새 프로세스 시작에 실패하면 이전 EXE 복원을 시도합니다. 복원도 실패하면 안내되는 백업 EXE와 결과 기록을 보관하세요. 재실행된 프로그램 자체의 모든 기능 이상을 자동 탐지하는 것은 아닙니다.

SHA-256은 다운로드 무결성 확인이며 코드 서명과 다릅니다. 현재 EXE는 코드 서명되지 않았습니다. NTFS hard link를 사용할 수 없는 임시 폴더에서는 안전하게 중단합니다.

## 배포 버전 규칙

- 공급 저장소는 `newskool4d-sketch/k-edufine-budget-dashboard`로 고정합니다.
- 더 높은 정식 버전의 Release만 대상입니다. 같은 태그의 EXE만 교체하거나 초안·사전 릴리스로 게시하면 자동 업데이트되지 않습니다.
- 태그는 `v10.0.0`, `v10.0.1` 형태이며, 자동 업데이트용 자산 이름은 항상 `2.대시보드_실행.exe`입니다.
- Release에 해당 EXE와 GitHub SHA-256 digest가 있어야 합니다. 최대 파일 크기는 150MiB입니다.
- 자동 확인은 EXE의 GUI 실행 시 동작합니다. Python 소스와 일반 변환 명령줄은 자동 네트워크 조회를 하지 않습니다.
